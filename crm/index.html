Connect to Airtable

Paste your own Airtable Personal Access Token. It is stored only in this browser's localStorage and sent only to api.airtable.com. Nothing is stored in this site's code.

How to create the token: go to airtable.com/create/tokens → Create token → add scopes data.records:read, data.records:write, schema.bases:read → under Access, add the base with ID app8zAXrWXaVWxxys → Create, then copy it here.

Demo with sample data: add ?mock=1 to the URL.
